# Lokerin Placeholder Assets

These files are valid placeholder PNGs and can be replaced later with final branding:

- `icon.png`: app icon source
- `adaptive-icon.png`: Android adaptive icon foreground
- `splash-icon.png`: splash screen image
- `favicon.png`: web favicon source

Keep the same filenames unless you also update `app.json`.

## Color Scheme

Use the light palette for primary store assets, icon backgrounds, splash, and favicon. The dark palette is included for optional dark-mode marketing screenshots or alternate assets.
