JobApply Tracker — Panduan Pengguna

Versi 1.0 · Penjelasan sederhana untuk pemakaian sehari-hari

Aplikasi ini membantu Anda menyimpan daftar lamaran kerja secara pribadi. Data Anda disimpan di ponsel atau tablet, bukan di situs web tempat Anda harus login.

Apa fungsi aplikasi ini

  • Mengingat perusahaan mana yang Anda lamar dan posisi apa (judul pekerjaan).
  • Melihat tahapan proses (misalnya: Applied = sudah melamar, Interview = wawancara, Offer = penawaran).
  • Menambah catatan, tautan, tanggal tindak lanjut, dan jadwal wawancara.
  • Mengekspor file cadangan kapan saja (Anda yang memilih mau dikirim ke mana).

Pertama kali membuka aplikasi

  1. Tunggu sebentar saat aplikasi menyiapkan penyimpanan di perangkat. Ini normal.
  2. Jika ada masalah, bisa muncul tombol Try again (Coba lagi) — ketuk satu atau dua kali.
  3. Anda akan melihat tiga tab di bagian bawah: Overview, Applications, dan Settings.

Tiga tab utama

Nama tab mengikuti tampilan aplikasi (bahasa Inggris).

Overview (Ringkasan)

  • Menampilkan jumlah lamaran per tahapan (misalnya Draft, Applied, Screening, dan seterusnya).
  • Menampilkan daftar singkat lamaran yang baru diperbarui.
  • Gunakan tab ini untuk melihat gambaran cepat proses mencari kerja Anda.

Applications (Lamaran)

Di sinilah Anda paling sering bekerja.

  • Kolom pencarian — Ketik sebagian nama perusahaan, judul pekerjaan, catatan, atau lokasi. Daftar akan disaring sesuai kata kunci.
  • Chip (tombol kecil berbentuk kapsul: Draft, Applied, All, dll.) — Ketuk untuk menyaring daftar. Ketuk All untuk melihat semua.
  • Daftar — Setiap baris adalah satu lamaran. Ketuk baris untuk membuka detail.
  • Tombol + — Ketuk untuk menambah lamaran baru.

Settings (Pengaturan)

  • Connectivity — Hanya informasi. Aplikasi tetap bisa dipakai tanpa internet untuk penggunaan biasa.
  • Export JSON — Membuat file cadangan. Lihat bagian “Mengekspor cadangan” di bawah.
  • Privacy — Pengingat bahwa data disimpan di perangkat.

Menambah lamaran baru

  1. Buka tab Applications.
  2. Ketuk tombol +.
  3. Isi formulir:
    • Company (Perusahaan) — Wajib diisi.
    • Role / title (Posisi / judul) — Wajib diisi (contoh: “Customer Support Specialist”).
    • Status — Ketuk baris status untuk memilih tahapan (misalnya Applied = sudah melamar).
    • Bagian opsional — Boleh dikosongkan:
      • Applied date (Tanggal melamar) — Contoh format: 2026-05-15 (tahun-bulan-tanggal).
      • Location (Lokasi) — Kota, remote, hybrid, dan sejenisnya.
      • Job posting URL — Tautan ke lowongan.
      • Compensation notes — Catatan soal gaji atau ekspektasi Anda.
      • Next follow-up — Kapan Anda ingin menindaklanjuti lagi.
      • Notes — Catatan bebas apa pun yang ingin Anda ingat.
  4. Ketuk Save application (Simpan lamaran).
  5. Anda kembali ke daftar dan seharusnya melihat entri baru.

Tips: Jika tombol simpan seolah tidak bereaksi, gulir ke atas dan pastikan Company serta Role sudah terisi.

Membuka dan mengubah lamaran

  1. Di tab Applications, ketuk baris yang Anda inginkan.
  2. Ubah apa pun yang perlu di layar detail.
  3. Ketuk Save changes (Simpan perubahan).

Menghapus lamaran

  1. Buka layar detail lamaran tersebut.
  2. Ketuk Delete (biasanya di bagian atas).
  3. Konfirmasi saat diminta. Penghapusan tidak bisa dibatalkan di perangkat ini.

Wawancara (Interviews)

Di layar detail, gulir ke bagian Interviews.

  • Ketuk Add untuk mencatat wawancara baru (bisa juga panggilan atau pertemuan).
  • Title (Judul) — Wajib (contoh: “Phone screen dengan perekrut”).
  • When (Kapan) — Opsional (teks tanggal/waktu biasa juga boleh).
  • Notes — Opsional.
  • Ketuk Save interview.
  • Untuk menghapus satu jadwal, ketuk ✕ pada baris tersebut lalu konfirmasi.

Mengekspor cadangan (JSON)

Mengapa perlu ekspor? Jika Anda ganti ponsel, reset pabrik, atau menghapus instalasi aplikasi, data bisa hilang jika tidak dicadangkan.

  1. Buka tab Settings.
  2. Ketuk Export JSON.
  3. Ponsel akan menampilkan layar Share (bagikan) seperti biasa.
  4. Pilih tujuan yang Anda percaya (email ke diri sendiri, Google Drive, folder Download, dll.).

Penting: File cadangan bisa berisi informasi pribadi. Bagikan hanya ke tempat yang Anda percaya.

Catatan: Pada beberapa versi aplikasi lewat peramban web, fitur ekspor bisa berbeda dengan di ponsel. Jika Anda mengandalkan cadangan, gunakan perangkat Android untuk mengekspor.

Bekerja tanpa internet

  • Anda bisa melihat, menambah, mengubah, dan menghapus lamaran tanpa Wi‑Fi atau kuota data.
  • Ekspor memakai layar bagikan bawaan ponsel; internet hanya diperlukan jika aplikasi tujuan Anda membutuhkan sambungan (misalnya unggah ke awan).

Penyelesaian masalah sederhana

MasalahCoba ini
Daftar kosong Ketuk All, kosongkan kolom search, atau ketuk + untuk menambah lamaran pertama.
Sudah simpan tapi tidak muncul Keluar dari tab lalu buka lagi Applications.
Ekspor tidak muncul Gunakan Android (disarankan). Tutup aplikasi lain lalu coba lagi.
Pesan error database Ketuk Try again. Jika tetap gagal, mulai ulang (restart) ponsel.

Privasi dengan bahasa mudah

  • Lamaran kerja Anda disimpan dalam file basis data di perangkat.
  • Aplikasi ini tidak mengirim daftar Anda ke server perusahaan secara bawaan kecuali nanti ada fitur tambahan yang disengaja (misalnya sinkron awan).
  • Anda yang mengontrol ekspor ketika mengetuk Export JSON dan memilih tujuan file.
